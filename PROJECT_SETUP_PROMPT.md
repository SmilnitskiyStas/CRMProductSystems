# AI Multi-Agent Claude Code Project Initialization

## Main Goal

Your task is to transform the current repository into a fully structured Claude Code multi-agent engineering environment.

The repository must support:

- multiple specialized agents
- reusable skills
- project documentation
- task orchestration
- logging and historical tracking
- handoff workflows between agents
- project memory and long-term context
- scalable AI-assisted software development

Use:

- `V1_spec.md`, `V2_spec.md`, `V3_spec.md` as the project-specific source of truth
- existing repository structure as the current project base
- existing `CLAUDE.md` generated by `/init` as the foundation

Do NOT replace existing important files.
Extend and improve them carefully.

---

# Initialization Rules

## Important Rules

- Never delete existing project files
- Never overwrite critical files without explanation
- Always preserve history and logs
- Always use markdown format
- Always use ISO dates: `YYYY-MM-DD`
- Always create task IDs
- Always create logs for completed work
- Always separate responsibilities between agents
- Always use reusable skills
- Always maintain architecture consistency

# Agent Workflow

All agents must follow this workflow:

1. Load context using workflow skills
2. Read relevant docs
3. Check task dependencies
4. Implement only assigned responsibilities
5. Update logs
6. Create handoff
7. Update task status
8. Update documentation if needed

---

# Multi-Agent Rules

- Agents must not overwrite each other’s work without reason
- Agents must respect boundaries
- All major changes must be logged
- Architecture changes must be documented
- Security-sensitive changes require security review
- Large changes require architecture review
- All completed work requires logging

---
