ADR-005: Worker scaffold як частина TASK-000
## ADR-005: Worker directory created in TASK-000, not TASK-008
Date: 2026-06-03
Status: accepted
Context:
BullMQ worker (ADR-001) потребує Node.js /worker сервісу.
Docker Compose і backend повинні знати структуру worker ще до TASK-008.
Decision:
/worker scaffold (package.json, src/index.ts, job stubs) створюється в TASK-000.
Реальна логіка (expiry-check, notification) — в TASK-008.
Consequences:
+ docker-compose.yml може включити worker service одразу
+ backend-developer знає queue names наперед
- Невеликий overhead у TASK-000

Деталізований план роботи TASK-000
Крок 1 — devops-engineer (паралельно з кроком 2)
Файл: docker-compose.yml
Додати:
 redis:
   image: redis:7-alpine
   ports: "6380:6379"   # 6379 може бути зайнятий локально
   volumes: redisdata
   healthcheck
 worker:
   build: ./worker
   depends_on: [postgres, redis]
   environment:
     REDIS_URL: redis://redis:6379
     DATABASE_URL: ...
Перейменувати DB: crm → shelfguard (або залишити crm для сумісності — рішення нижче)
Рішення щодо DB name: залишаємо crm до TASK-001 (rename) щоб не зламати поточний backend. TASK-001 перейменовує проєкти і connection string разом.
