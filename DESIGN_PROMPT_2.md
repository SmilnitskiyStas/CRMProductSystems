> Промпт для Claude / v0.dev / Figma AI
> Охоплює: Web CRM + Mobile App (v1.0) + Auto Order UI (v2.0)

---

## 🎨 ЗАГАЛЬНИЙ СТИЛЬ ТА БРЕНД

### Характер продукту
ShelfGuard — B2B інструмент для роботи, не маркетинговий сайт.
Індустріальний, точний, функціональний. Кольорові статуси — основний
комунікаційний інструмент, їх ніколи не ховати і не пом'якшувати.

### Що РОБИТИ:
- Темна тема як основна
- Чіткі межі між блоками
- Функціональна щільність (dense tables)
- Контрастні кольори статусів
- Моноширинний шрифт для чисел і дат

### Що НЕ РОБИТИ:
- Градієнтний purple/pink фон у стилі SaaS лендінгів
- Пастельні bubble-картки
- Робити кнопки "Списати" і "Зберегти" однакового вигляду
- Ховати або пом'якшувати статусні кольори
- Використовувати тільки Inter (нудно)

**4 великі метрики (рядок зверху):**
```
┌─────────────────┐ ┌─────────────────┐ ┌─────────────────┐ ┌─────────────────┐
│  🟢 847         │ │  🟡 23          │ │  🔴 8           │ │  ⚫ 2           │

└─────────────────┘ └─────────────────┘ └─────────────────┘ └─────────────────┘
```

Фон кожної картки = відповідний `*-bg` колір.
Число великим шрифтом (48px bold), моноширинне.

**Центр: Таблиця "Потребують уваги"**

Фільтр-таби зверху: [Всі 33] [Warning 23] [Critical 8] [Expired 2]

Колонки:
```
□  [фото]  Товар           Штрихкод      Зона       К-сть  Термін    Днів  Статус    Дія
□  [img]   Молоко 2.5% 1л  4820001234    Холодильн  48 шт  15.01.26    5   🔴        ⋮
□  [img]   Хліб білий       4820005678    Хлібний    12 шт  20.01.26   10   🟡        ⋮
```

- "Днів" — моноширинний, колір = статус
- "Статус" — кольоровий badge з текстом
- "Дія" ⋮ → dropdown: Знижка / Перемістити / В кулінарію / Списати
- Рядок EXPIRED: злегка затемнений рядок (opacity 0.7)
- Мультивибір чекбоксами → масова дія

**Правий сайдбар (280px): Швидкі дії**

                Кнопки: accent-hover при hover + transition 150ms

                Помилка: error notification
                Підтвердження: medium impact
