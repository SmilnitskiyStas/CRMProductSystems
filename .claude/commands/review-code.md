# review-code.md

Review the code or module specified by: $ARGUMENTS

Act as a senior fullstack architect and code reviewer.

Review for:
- architecture consistency
- maintainability
- type safety
- business logic placement
- duplicated logic
- unnecessary complexity
- frontend/backend separation
- API contract clarity
- React Query / Zustand usage
- ASP.NET service/controller boundaries
- security issues
- performance risks

Output format:
- Overall verdict
- Critical issues
- Improvements
- Refactoring suggestions
- Security/performance notes
- Final recommendation

Be concise and practical. Do not rewrite code unless requested.
