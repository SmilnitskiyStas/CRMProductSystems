## What changed

Backend groundwork for the floor-plan canvas feature (TASK-715/716). New flat join entity
`ItemZoneAssignment` (table `item_zone_assignments`, no soft-delete) lets a catalog `Item` be
tagged with one or more `LocationZone`s. Mirrors the existing `ProductSupplierSetting` pattern.

- `ShelfGuard.Domain/Entities/ItemZoneAssignment.cs` — new entity (Id, TenantId, ItemId, ZoneId, CreatedAt, Item?, Zone? nav).
- `AppDbContext.cs` — `DbSet<ItemZoneAssignment>` + config block (unique index on `(ItemId, ZoneId)`, index `idx_item_zone_assignments_tenant_zone` on `(TenantId, ZoneId)`, both FKs cascade).
- Migration `20260917145906_AddItemZoneAssignments` — table + indexes generated by EF, RLS block hand-appended to `Up()` (copied verbatim from `AddMobileCatalogLocations`): `tenant_isolation` + `provider_bypass` + `worker_bypass`. No `store_scope` policy — catalog metadata, same category as `items`/`location_zones`. `Down()` drops the table. Verified the model-snapshot diff touches only the new entity (53 insertions, nothing else).
- `IItemRepository`/`ItemRepository` += `GetZoneAssignmentsAsync` (includes `.Zone.Location`), `ZoneAssignmentExistsAsync`, `GetZoneAssignmentAsync`, `AddZoneAssignmentAsync`, `RemoveZoneAssignment`.
- `ILocationRepository`/`LocationRepository` += `GetZoneWithLocationAsync` (new sibling method, `GetZoneByIdAsync` left untouched since update/delete reuse it).
- `IItemService`/`ItemService` += `GetZonesAsync`, `AssignZoneAsync` (404 "Product not found."/"Zone not found." incl. explicit `zone.Location.TenantId != tenantId` cross-tenant guard on top of RLS, 400 "Zone assignment for this product already exists."), `UnassignZoneAsync`. New `ILocationRepository` constructor dependency (already in DI, no DI file changes needed).
- `ItemDto.cs` += `ItemZoneDto`, `AssignItemZoneRequest`.
- `ItemsController.cs` += `GET/POST /api/items/{id}/zones`, `DELETE /api/items/{id}/zones/{zoneId}` (POST/DELETE gated `AtLeastStoreManager`), mirroring the suppliers block + `LocationsController.DeleteZone`.
